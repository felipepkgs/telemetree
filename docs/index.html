A SQL editor for queries you keep, not tabs you lose.

Telemetree is a fast, keyboard-first native macOS SQL client for MySQL, PostgreSQL and SQLite — Swift and AppKit, not Electron. Built around persistent query documents and a snippet library, instead of the disposable tabs most SQL clients give you.

Features

Everything that's actually built

No vaporware — this is what runs today, from the app's own milestone spec.

Persistent query documents

Named queries organized in folders in the sidebar, autosaved as you type — the way a code editor treats files, not the way a SQL client treats tabs.

Snippet library

Reusable SQL snippets in their own folder tree — create, edit, insert into the current query, with hover-to-delete and confirmation before anything's removed.

Syntax highlighting & autocomplete

Keyword-level SQL highlighting plus a custom completion popup — keywords, real table names after FROM/JOIN/etc., and real column names (scoped to the tables the current statement references) everywhere else, all correct case. Only Tab ever accepts a suggestion.

Command palette

⌘⇧P jumps straight to any query, snippet, connection, or action — arrow keys and return, no mouse required.

Query history

Every executed query is logged — connection, timestamp, success or failure — searchable, capped at 500 entries, double-click to reopen.

Destructive SQL guard

DELETE, DROP, TRUNCATE, and every UPDATE — WHERE clause or not — require Touch ID before they run.

Preferences

App theme, syntax highlighting theme, and editor font/size — four highlighting palettes, three font choices, applied live everywhere text renders, results grid included.

Paginated results

A plain, un-LIMITed SELECT pages in 100 rows at a time with numbered page navigation ("1-100 of 10,000"), instead of pulling an entire result set into memory.

Keychain-backed credentials

Passwords never touch disk in plaintext. No account, no cloud, nothing phones home — just this app and your database.

In practice

Reach for it, don't dig for it

The two features that get used every session: everything's one keystroke away, and a bad query gets caught before it runs.

Multi-statement editing. The caret decides which statement runs — keywords, strings and numbers are colored independently as you type.
One list, everything in it. Queries, snippets, connections and actions, filtered as you type.
Changes apply live. Switch a syntax theme in Preferences and every open document updates immediately — no reload.
Large tables stay responsive. A SELECT with no LIMIT pages in 500 rows at a time — Load More fetches the next page instead of pulling everything into memory.
A bad DELETE can't slip through. DELETE, DROP, TRUNCATE, and any UPDATE without a WHERE stop for Touch ID first — cancel and nothing runs.

Appearance

Vapor, in three materials

Vapor is the default theme — a dark glass panel with a pulsing connection-status dot. Gold, Silver and Carbon Fiber restyle the same chrome with a different accent, each carrying its own dot gradient through the toolbar, status bar, and active tab.

Vapor — Gold

Warm gold fill and glow, carried into the tab pill and status dot.

Vapor — Silver

Cool, neutral metal fill for a quieter default.

Vapor — Carbon Fiber

A real woven diagonal texture in the bars, with a red accent identity.

Switch themes from the Theme menu, or via the command palette — Theme: Vapor, — Gold, — Silver, — Carbon Fiber.

Where it stands

Honest status, not a launch page

This is a personal project, built and used against real MySQL, PostgreSQL, and SQLite databases. Releases are ad-hoc signed, not notarized — Gatekeeper will still flag the first launch.

Shipped — Milestones 1–5

  • Connections — add, test, save connections for MySQL, PostgreSQL, or SQLite; password in Keychain (SQLite is just a file, no credentials needed)
  • Three real database engines, not a MySQL-only client with the others faked — engine-specific identifier quoting, error translation, and schema browsing (Postgres has no cross-database USE, so that's handled honestly instead of papered over)
  • Query documents & folders — persistent, tabbed, autosaved
  • Snippet library — folders, create, edit, insert, hover-delete
  • SQL syntax highlighting, plus a custom completion popup: keywords; real table names after FROM/JOIN; real column names scoped to the statement's tables once a FROM exists; and, before one exists, qualified table.column suggestions across every known table — accepting one inserts the column and appends the matching FROM clause for you, cursor left exactly where you were typing. Tab-only accept.
  • Last-clicked database as default (MySQL) — clicking a database in the sidebar runs a real USE, so unqualified table names resolve without db.table qualification
  • Command palette (⌘⇧P) and sidebar search, sorted by most-used
  • Query history — searchable, capped, reopenable
  • Vapor theme family — base, Gold, Silver, Carbon Fiber
  • Destructive SQL guard — every DELETE/DROP/TRUNCATE/UPDATE requires Touch ID, no exceptions
  • Preferences — theme, syntax highlighting, editor font/size (applies everywhere text is rendered, results grid included)
  • Paginated results — 100 rows at a time with numbered page navigation ("1-100 of 10,000"), not an unbounded "Load More"
  • Export results — CSV or JSON, alongside plain copy-to-clipboard
  • Save query as… — name and file an unsaved query straight from the editor toolbar, with a folder picker if you have any
  • Accurate DML row counts — INSERT/UPDATE/DELETE show the real affected-row count, not always 0
  • Active-statement highlighting — the editor shows exactly which statement Run/⌘Return will send
  • Friendly error messages — common MySQL and PostgreSQL error codes translated to plain English, not raw server text
  • VoiceOver support — tabs, icon-only buttons, and sidebar rows are properly labeled
  • Single-instance guard — launching a second copy activates the running one instead of running two side by side
  • Custom app icon
  • Downloadable release — brew install --cask telemetree, or a zip on GitHub Releases (ad-hoc signed, not notarized)

Not built yet

  • System light/dark appearance — Vapor is fixed-dark for now, by design, deferred to the very end of the project
