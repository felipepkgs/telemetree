A database workspace that remembers the work.

Useful SQL stays organized, execution stays scoped, and the active schema informs the tools around it.

Queries become documents

Name and organize ongoing SQL in the sidebar. Documents persist across launches; temporary table browsing stays temporary.

Execution stays scoped

⌘Return runs the selected SQL or the statement under the cursor. Destructive statements pause for Touch ID or your Mac password.

Assistance knows your schema

Search Everywhere and SQL completion use the active database's tables and columns. Format or inspect structure without losing your place.

Results are ready to use

Page through large results, sort, copy, export CSV or JSON, and edit eligible rows with a primary-key check.
